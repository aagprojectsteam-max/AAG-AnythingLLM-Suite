# Doctor

Run `./doctor.sh`. Package mode validates OS/runtime tools, JSON, JavaScript, sanitization, core layout and patch metadata. Installed mode reports AnythingLLM compatibility, skills, artifacts/PDF, Chess, Composer, progress/cancel, Atlas, ComfyUI, local LLM, Stockfish, canonical hashes, every model dependency and hardware capability. `MISSING` and `OPTIONAL` lines include the component that must be configured; structural or compatibility failures produce a nonzero exit.
